# 結果表の書き方

是正の対応表のうち、確認後の結果表の書き方。方針表と同じ番号の行を引き継ぎ、列を足す。

## 列

| 列 | 書くこと |
|---|---|
| 番号 | 方針表と同じ番号 |
| 決めた動き | 方針表のまま |
| 結果 | 実際に確かめた値や動き。「決めたとおり」とだけ書かない。決めた動きと違う行、確かめていない行は、そう書く |
| 確かめ方 | 例: 単体の試験／結合の試験／入口から通す試験（画面、API、コマンドなど）／目視（画面、出力、ログ）／回帰の基準との突き合わせ／原典との突き合わせ／読んだだけ。案件の入口に合わせて選ぶ。試験だけで確かめた行と、実物を見て確かめた行を区別できるようにする |
| 確かめた結果 | 確かめ方を実行して出たこと。確かめ方と同じ列に混ぜない |

- 1行を複数の手段で確かめたときは、確かめ方に番号を付け、確かめた結果も同じ番号で対応させる（例: 確かめ方「(1) 結合の試験 (2) 画面の目視」、確かめた結果「(1) n 件通過 (2) 一覧に新しい項目が出ることを目視」）。
- 試験なら、その行を見ている試験の件数と、通過・失敗を書く。
- 試験の無い行は「試験なし」と書く。別の行の試験が同じ分岐を通るなら、その番号を添える。
- 1つの試験が複数の行を見るときは「# N と同じ n 件」と書いてよい。

## 表の前に書くこと

- 承認を求める直前の版で回し直したこと。その後に変更があれば、何を変えたか。
- 回した環境。
- 冒頭の結論の数え方を固定する: 全行数、決めたとおりだった行、違った行、確かめていない行。合計が全行数と一致すること。

## 同じ形の箇所の表

| 列 | 書くこと |
|---|---|
| 探した形 | 直した箇所の名前ではなく、ほかにも当てはまる言い方 |
| 探し方 | 検索の式や読んだ範囲 |
| 件数 | 0件でも書く |
| 扱い | 今含める（人の承認の後）／別の課題として起こす／既知のリスク |
