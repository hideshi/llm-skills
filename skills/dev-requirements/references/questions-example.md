# 確認事項の記録の例

型: 確認事項の記録
形の一例。正本は型の一覧の欄。形式・節名・置き場所は任意で、案件に既に形があればその形に従う。値はすべて作り物。

題材は、確定した請求書の明細を直せないようにする変更。この例では、表ではなく、確認事項ごとの箇条書きで書いた（表にしてもよい）。人の名前は書かず、役割で書いた。

## `Q-3`

- 質問文: 確定した請求書の明細を、確定の後に直してよいですか。
- 備考: 今は、確定した後も画面から明細を直せる（現状の振る舞いの記録の観察）。直すと、取引先に送った請求書と社内の記録が食い違う。直せないようにするのが良いと推測している。
- 回答: 「直せないようにしてください。直したいときは取り消して作り直す運用にします。」
- 回答日: 2026-11-02
- 答えた人と伝えた人: 経理の責任者が答え、営業の担当が伝えた
- 論点の名: 確定した請求書の明細の変更
- 状態: 確定
- 回答の戻し先: モデル

## `Q-4`

- 質問文: 確定した請求書を取り消せるのは、誰ですか。
- 備考: 今の画面は、取り消しのボタンを経理の責任者にだけ見せている。権限の資料は見つからなかった。
- 回答: なし（まだ答えが無い）
- 回答日: なし
- 答えた人と伝えた人: なし
- 論点の名: 請求書の取り消しの権限
- 状態: 未回答
- 回答の戻し先: モデル

## `Q-5`

- 質問文: 確定済みで明細を変えられないことを伝える文に、確定日も添えてほしい、という意見をどう扱いますか。
- 備考: 画面の設計の案を見せたときに、経理の担当が出した意見。原文は「確定日もあると、問い合わせのときに助かります。」。見せ方だけの意見で、規則と流れは混ざっていない。
- 回答: 「添えてください。」
- 回答日: 2026-11-05
- 答えた人と伝えた人: 経理の責任者が答え、営業の担当が伝えた
- 論点の名: 確定済みの理由の見せ方
- 対象: 画面 `SC-3` の、明細の表の上の文
- 状態: 確定
- 回答の戻し先: 画面
- 振り分けた結果: 戻し先を画面にし、画面の設計の文言に反映した（ほかの画面に効く部品やトークンの定義ではない）。

この例の「振り分けた結果」は、単位の本文が画面への意見ごとに求める1行で、型の欄ではない。
