## 7. 次フェーズ条件（`jev-calibration`）
次を満たすとき `jev-calibration` へ進む。

- [ ] `datasetStatus: frozen`
- [ ] `datasetVersion` が記録されている
- [ ] リーク防止チェックに致命的 fail がない（または受容理由が承認済み）
- [ ] ラベル空間が architect スキーマと整合
- [ ] ゲート基準・初期閾値仮説が較正の入力として用意されている（値はプロジェクト入力）

差し戻しが必要な場合:

- スキーマ不整合 → `jev-logic-architect`
- ラベリング品質・一致率の問題 → データ整備プロセス（本スキルの再 freeze 前に実施）
