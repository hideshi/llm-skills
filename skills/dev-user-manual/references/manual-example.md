# 操作マニュアルの例

型: 操作マニュアル（部分例: 章の本文を除く欄）
形の一例。正本は型の一覧の欄。形式・節名・置き場所は任意で、案件に既に形があればその形に従う。値はすべて作り物。

題材は、確定した請求書の明細を直せないようにする変更のあとの、経理の担当向けの操作マニュアル。この例では、仕事の台帳の行を3行、章の記録を2行に絞った。「はじめる」の章と「うまくいかないとき」の章、配る形に入る章の本文（手順そのもの）は省いた。台帳と確かめた記録は内部用で配る形には含めないが、この例では見せている。

## 読む人、範囲、正本

| 項目 | 値 |
|---|---|
| 読む人 | 経理の担当（請求書を作って確定する役割） |
| 範囲 | 下書きの請求書への明細の追加と、請求書の確定。取引先の登録（画面 `SC-5`）は、既存のマニュアルが扱うので範囲外 |
| 正本の所在 | 案件の決まりが無いため、一つのファイル（`docs/example-manual.md`）を正本にした |

## 仕事の台帳（内部用）

| 識別子 | 仕事の名前（利用者の言葉） | 根拠 | 判断 | 理由 | 章 |
|---|---|---|---|---|---|
| `MW-1` | 下書きの請求書に明細を足す | 画面（`SC-3`。テストケース `TC-42`） | 載せる | 確定の前に必ず通る仕事。確定の後は直せなくなることを、手順の中に書いた | 章2 |
| `MW-2` | 請求書を確定する | 画面（`SC-3`。テストケース `TC-44`） | 載せる | 今回の変更の中心。確定の後は明細を直せないことを、できた状態に書いた | 章3 |
| `MW-3` | 確定した請求書の明細を直す | 聞き取り（経理の担当から「確定の後に直せないか」と聞かれた） | 対象外 | 確定した請求書の明細は直せないので、仕事として成立しない。迷ったときの案内は「うまくいかないとき」の章に書いた | 当てはまらない（対象外のため） |

## 章の記録（内部用）

| 章 | 仕事 | 辿った段 | 確かめた日 | 環境 | 版 |
|---|---|---|---|---|---|
| 章2 | `MW-1` | 実際の画面で辿った | 2026-11-14 | 点検用（隔離した環境。作り物のデータと作り物の利用者で、外部への送信は捕まえた） | `d4e5f6a`（本番に載せる予定の版。反映は 2026-11-15 の予定） |
| 章3 | `MW-2` | 実際の画面で辿った | 2026-11-14 | 章2 と同じ | `d4e5f6a`（章2 と同じ） |

「仕事」の欄は、仕事の台帳との対応を示すために案件で足した補助欄で、型の欄ではない。

## そのほかの欄

| 項目 | 値 |
|---|---|
| もとにした画面の設計の版 | 画面の設計（`docs/example-screen.md`）の、2026-11-06 に人が採った版 |
| 見直すきっかけ | 画面の変更の連絡があったとき。または確かめた日から 90 日 |
| 未確認の章の一覧 | なし |
| 確定でない章の一覧 | なし（この例で省いた2つの章も、実際の画面で辿って確定した） |
| 問題台帳に入れた食い違いの一覧 | なし |
| 配る範囲 | 経理の担当の全員に、全章（管理者向けの章は無い） |
| 配る形の記録 | PDF に変換し、変換した後の実物を開いて、目次・章・画像がそろっていることと、内部用の台帳と確かめた記録が入っていないことを確かめた（2026-11-14） |

「確定でない章の一覧」と「問題台帳に入れた食い違いの一覧」は、単位の本文（終了条件）が求める項目で、型の欄ではない。
