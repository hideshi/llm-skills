# 帳票

[SKILL.md](../SKILL.md) の手順4で、画面の外へ持ち出す形の決まった文書（請求書、領収書、明細、証明書の類）を設計するときの決まり。

## 帳票とするもの

- 帳票は、画面の外へ持ち出され、形が決まっていて、後から読まれる文書。印刷用の Web の頁でも、持ち出して保存・提出するならここで扱う。
- 表計算の形式への書き出し（CSV など）は、機械が読む形なら呼ばれる契約とデータの側で扱う。人が読む帳票として形を決めるときだけ、ここで扱う。

## 欄

文面の一覧の欄に加えて、帳票では次を決める。

| 欄 | 中身 |
|---|---|
| 項目と並び | 載せる項目、並び、見出し、繰り返す明細の行 |
| 値の出どころ | 項目ごとの出どころ（データ、業務規則の計算）。式と端数処理は業務規則を指す |
| 表示の書式 | 桁区切り、表示の桁、通貨と単位、日付の書き方 |
| ページ | 1ページに収まらないときの切れ目、繰り返す見出し、合計を書く場所 |
| 出力の形式 | PDF など。形式に依る作り方は、道具の資料か案件の決まりに従う |
| 法定の記載 | 一次情報の記録の項目と、その帳票への適用を決めた要件・業務規則。無ければ「決定待ち」 |
| 発行の時点の値 | 発行した後に元のデータが変わったとき、帳票に発行の時点の値を残すか（業務規則を指す） |

## 決まり

- 計算と端数処理を、帳票の側で決め直さない。業務規則に無ければ上流へ返す。
- 法定の記載事項が当たるかを、この単位で解釈しない。一次情報の記録と、適用を決めた要件か業務規則を指す。
- 発行済みの帳票の訂正、再発行、採番の決まりは、業務規則とデータの側で決める。帳票の側は、それを表示する欄だけを持つ。
- 出力した後の実物（PDF など）を開いて、項目の欠け、桁の溢れ、ページの切れ目を確かめる。
