## 独自の判断

| 決まり | 理由 | 確かめ方 |
|---|---|---|
| カードの項目0で、採否を決める・根拠に答える・点検を実行する・止めて直す・影響を受ける、の役割を先に決める | 問いの宛先と採否の主体が決まらないと、複数の人が関わるリポジトリで、だれの答えをもって答えられたとするかが曖昧になるため（典拠の v1.0.0 には、この手順の記述は無い） | 役割が複数の人に分かれたカードで、問いの宛先を誤った件数と、採否の主体が分からず止まった件数を記録し、役割の分け方を見直す |
| 根拠の種類を、文書・設定・コード・導出・持ち主の答え・推測の6つに分け、導出は「導出・未確認」の印を付けてカードの項目0〜4、6に置き、所在の無い推測は項目5の問いにだけする | 失敗空間と点検が見ていないものは文書にほとんど書かれず、推測を締め出すとカードの中心が空になる。一方で、読みを事実の顔で置くと、持ち主が確かめずに受け取るため | 導出の行が、後で持ち主の答えや文書で覆された割合を記録する。高ければ導出の扱いを項目5だけに狭める。低くても、印を読み飛ばして事実と受け取った件数を見る |
| 「任せる」の段に、一行ずつは読まない実装の細部を入れる。条件は、後で直せる、項目4のどれかの点検が見ている、被害が持ち主の外へ及ばない | 3段のどこにも入らない実装の細部が、実際には大部分を占めるため。点検が見ていて後で直せるなら、誤りの検出と訂正は点検を通して満たせると読んだ | 「任せる」にした領域で起きた不具合のうち、点検が拾わなかったもの、持ち主が採否に答えられなかったものの件数を記録し、条件を見直す |
| 1回に出す問いを5〜8個にし、決めた順（変更が触れる箇所、深く理解する段の残った問い、深く理解する段の未出題、それ以外の残った問い、それ以外の未出題）で選ぶ | 一度に多く問うと答えが浅くなり、少なすぎると項目5が減らないため。順は、保留の促しに直結する問いを先に、次に前に答えられなかった問いを先にするため。数の目安に、典拠や外部の根拠は無い | 出した数と、答えられた割合、答えの質（文書と合ったか）を記録し、数を見直す。順位4・5の問いが何回の機会にも出されず残った件数と、変更を採る前の回が2回以上に分かれた件数を記録し、順を見直す |
| 約束すること・約束しないことを、3行程度で、保証の範囲と明記された対象外・未検証の点に限って書く | 持ち主が問われたときに最初に答える「何を保証し、何を保証しないか」を、文書にある範囲で短く押さえるため。行数の目安に根拠は無い | 持ち主が、カードに書いた範囲の外の保証を求められて答えられなかった件数を記録し、書く範囲と行数を見直す |
| 失敗空間を5つ前後に絞り、被害が持ち主の外へ及ぶもの、取り返しがつかないものを先に並べる | 1枚に収め、持ち主が覚えて答えられる数にするため。数の目安に根拠は無い | 絞って外した失敗が、後で実際に起きた件数を記録し、数と絞り方を見直す |
| 理解の深さを3段（深く理解する、地図だけ持つ、任せる）に分け、「地図だけ持つ」は地図に当たる文書の所在を持つこととする | このスキルを依頼した持ち主が示した案の3段に合わせた。「地図だけ持つ」を、典拠の (0) の失敗空間の地図のうち、内部の構成について「どこに何があり、壊れたらどこに症状が出るか」を知っていることと読んだ | 「地図だけ持つ」にした領域で起きた不具合で、症状から場所を持ち主が言えなかった件数を記録し、段の分け方を見直す |
| 深く理解する段の問いは、下書きを見ずに答えられたときだけ項目5から外す | 下書きを見ながらの答えは、地図を読めることの確かめにはなっても、地図が持ち主のものになったことの確かめにならないため | 見ずに答えられた問いと見て答えた問いで、後の更新で同じ問いに答えられた割合を比べ、決まりを見直す |
| 流れの問いは、深く理解する段の問いと同じに扱い（外す条件、保留の促し）、この行に触れる変更は、受け取るもの・出すもの・残すものを変える変更に限る | 流れはほかの項目を読む起点で、外へ送るもの・保存するものを含むため。触れる変更を広く取ると、どの変更も保留の対象になって促しが効かなくなるため | 流れの問いが項目5に残っていた間に採った変更のうち、入出力や保存を変えていなかったのに後で流れの行を直す必要が出た件数を記録し、「触れる」の範囲を見直す |
| 公開扱いのリポジトリでは、カードをリポジトリの外に置くのを既定にする | 失敗空間、点検が見ていないもの、説明できない箇所は、弱点の一覧として読めるため | 外に置いたカードと中に置いたカードで、更新の頻度と、置き場所が原因で読まれなかった件数を比べる |
| 更新では、状態を下書きに戻し、前の版の「採った」を持ち越さない。期間による見直しでは、変更が無くても項目5に残っている問いを出し直す | 採否は版ごとの判断であるため。また、残った問いを減らす機会を、変更が無くても作るため（典拠の (0) を、運用を通じて獲得するものと読んだ） | 期間による見直しで項目5から外れた行の数と、何回の見直しでも残り続けた行の数を記録し、見直しの期間と出し直す範囲を見直す |
