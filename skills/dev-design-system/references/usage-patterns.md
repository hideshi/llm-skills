# 使い分けの例

使い分けの決まりを書くときの例。どれも規範ではなく、案件で採るかを決める（採ったら、採った理由と一緒に設計の判断に書く）。

## ボタンの3つの軸

| 軸 | 例 |
|---|---|
| 優先の語 | 主、副、三次 |
| 塗りの段 | 塗り、枠と淡い色、枠なし |
| 大きさ | 標準、強調 |

- 軸を混ぜない。一番下の段を、真ん中の段と同じ語で呼ばない。
- 優先の語の数と、塗りの段の数を合わせる。
- 大きさの段は少なくする（例: 2段まで）。主を大きく、ほかを極端に小さくしない。
- 公開面の「主な操作は画面に1つ」は、主の数の決まりで、管理面の段の数を減らす根拠にしない。
- 主でないボタンも、上に乗る前から押せる見た目（枠か背景）にする。

## 状態の色

| 例 | 理由 |
|---|---|
| 緑は、終わった状態（最後の成功）だけに使う | 途中の状態（送った、確かめ待ち）を終わりと読まれないようにするため |
| 途中の状態は、青か黄にする | 進んでいることと、注意が要ることを分けるため |
| 新しい状態の表示は、既にある形を使い、色だけを変える | 形の種類を増やさないため |

## 知らせ方

| 知らせ方 | 向いている場面 |
|---|---|
| その場（項目の近く） | 入力の誤り |
| 帯（画面の上） | 画面全体に効く知らせ、続く警告 |
| 一時の知らせ | 操作が終わったこと（読み上げにも届くようにする） |
| ダイアログ | 取り消せない操作の確かめ |

## 表

- 数の値は右に寄せ、見出しは左のままにする。対になる数の列は同じ幅にする。
- 状態の表示の列は、折り返さない幅にする。
- 幅を決める列と、残りを受ける列を組で決める。
