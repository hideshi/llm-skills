# 部品の仕様の欄

部品ごとに、設計の判断の部品の一覧に書く欄。道具や枠組みに依らない言い方で書く。

| 欄 | 書くこと |
|---|---|
| 名前 | 行の鍵。画面の設計とワイヤーはこの名前で指す |
| 目的 | 何のための部品か（1文） |
| 使う場面・使わない場面 | 似た部品との分け目 |
| 構成 | 中の要素（ラベル、本体、補助の文、アイコンなど）と、どれが省けるか |
| 種類 | 見た目や役目の違い（優先の語、塗りの段、大きさ） |
| 状態 | 既定、上に乗った、フォーカス、押下、無効、読み込み中、選択、エラー、読み取り専用、空のうち、持つもの |
| 入力・出力・イベント | 受け取る値、返す値、知らせる出来事（道具の書き方ではなく、意味で） |
| 選択と展開 | 選べるか、開け閉めできるか、その状態をどう知らせるか |
| フォーカスの管理 | 開いた時にどこへ移るか、閉じた時にどこへ戻るか、中に閉じ込めるか |
| キーボードの操作 | Tab、矢印、Enter、Space、Esc で何が起きるか |
| 役割・名前・状態 | 支援技術に伝わる役割と名前と状態。素の HTML の要素で伝わるなら、その要素 |
| 内容の決まり | ラベルの長さ、切り詰め、アイコンだけのときの名前 |
| アクセシビリティの基準 | 割り当てた基準の番号（コントラスト、フォーカス、的の大きさなど） |
| 関係する部品 | 組み合わせて使う部品、置き換える部品 |

## 書くときの注意

- 素の HTML の要素（ボタン、リンク、選択、チェック）で足りる部品は、要素の名前を書くだけにし、独自の役割を作らない。
- ダイアログやメニューのように、キーボードの操作とフォーカスの決まりが定まった型がある部品は、その型（W3C の ARIA の手引きの型など）を指し、違う所だけを書く。
- 状態は、画面の設計の状態（空、読み込み中、失敗、権限なし）と対応がとれるようにする。
- 色だけで状態を伝えない（文字かアイコンを添える）。
