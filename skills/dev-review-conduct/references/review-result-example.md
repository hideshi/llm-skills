# レビュー結果の例

型: レビュー結果
形の一例。正本は型の一覧の欄。形式・節名・置き場所は任意で、案件に既に形があればその形に従う。値はすべて作り物。

題材は、確定した請求書の明細を直せないようにする変更への、最初のレビューの結果。節の並びは、単位の本文の「結果の形」に合わせた。この例の識別子は、同じ題材のほかの単位の例と同じものを使う。

対象の識別子: 要件 `REQ-7`、差分 `b2c3d4e..c3d4e5f`（依頼と一致することを確かめた）。作った側の説明は読んでいない（依頼文の事実と原典だけを読んだ）。

判定: 変更要求（重大度「中」の指摘があるため）。

- 要求と変更・試験の対応: `AC-21` → `TC-41`、`TC-43`。`AC-22` → `TC-44`（未実施。`R-3`）。`AC-23` → `TC-42`。対応の無い要求は無い。
