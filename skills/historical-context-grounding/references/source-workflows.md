# 資料の取得・判定の手順と記録

時代考証のための資料の取得・保存と、資料の信頼性・適合性の判定の扱い。全分野の裏取りを一つの基準へ統一するものではない。

## 別の手順が指定されている場合

利用者や案件が、資料の取得・保存・索引、または資料の採用判定の手順（別のスキルや規程）を指定している場合は、その本文を読んで従う。

1. 利用者が指定した参照元、ホストが公開する利用可能なスキル、既知の作業・参照リポジトリから本文を読む。特定のホームディレクトリや隣接配置を前提にしない。
2. 読んだ本文の版（リポジトリとコミット、または配布版）と、本文のSHA-256を記録する。作業中の変更がありうるため、コミットだけで済ませない。
3. READMEや検索要約だけで、その手順を実施したことにしない。読めない場合は、下の基本手順を使い、指定の手順は未実施として記録する。自動インストール、submodule追加、認証設定、外部リポジトリへの変更は、この参照のために行わない。
4. 指定の手順が定める採用基準（等級表、合格条件など）を、このスキルで複製・変更しない。採用可能な資料であることと、個別の歴史的判断が確定することは分ける。
5. 指定の手順が映像など別の用途向けの出力（場面ID、タイムコードなど）を求める場合でも、その用途の作業を開始しない。必要な項目の対応を示し、適合できない部分は差分として記録する。

## 基本手順（指定がない場合）

- 根拠本文と所在を実際に確認し、主張を支える箇所、成立時期・版、対象への適用範囲を残す。
- 取得・保存できたものと、本文未読・取得不能・推測を分ける。保存先やハッシュを捏造しない。
- 保存する場合は、利用者が指定した案件・実験の成果物フォルダ内に置く。スキルリポジトリには資料を保存しない。
- 根拠の強さ、競合する資料、言える範囲と未確認点を明示する。

この基本手順は、専門の資料判定手順の代わりではない。依頼がそうした手順の正式な実施を必要とする場合、その部分は未実施として返す。

## 案件側へ残す利用記録

使った手順（指定の手順か基本手順か）、指定の手順ならその版と本文のSHA-256、ローカル変更の有無、成果物の所在を記す。別版・出力形式の対応・未実施の部分があれば、その差を添える。不明は不明と書き、未読を確認済みにしない。
