# Historical Context Grounding

人物の選択や制度の働きを「自然／不自然」「当時なら当然」と評価する前に、その判断を支える時代背景を確認する。現代の直感、著名人物のイメージ、AIの出力だけを根拠にしない。史実の再現、史実に着想を得た架空世界、後世の物語の再現を区別し、利用者が選んだ創作方針を尊重する。

## 判断を変える前提に絞る

対象の時代・地域・身分・制度と、裏取りする命題を特定する。たとえば「家族のために主君のもとを離れることは、その社会でどう評価されたか」。既存の企画・依頼から分かる範囲で着手し、細部をすべて確認するまで作業を止めない。史実との一致を求めていない創作へ、無関係な考証を広げない。

特に次を点検する。

- 同じ名称が異なる関係を指していないか。合意による保証、戦時の捕縛、明示的な脅迫などを、単に同じ「人質」として扱わない。
- 当人の務めが誰に向いているか。親、妻子、一族、個人としての主君、王朝、共同体などを一括りにしない。
- 個人の選好だけでなく、慣行・法・評判・周囲の期待が選択の意味を変えないか。

## 資料の取得・判定は既存手順へ接続する

資料を探して保存する時、または根拠として採用する時は、[資料の取得・判定の手順と記録](references/source-workflows.md)を読む。利用者や案件が別の手順を指定していればそれに従い、このスキルで採用基準を再定義しない。指定がなければ同資料の基本手順を使う。使った手順と版の記録方法も同資料に従う。

ここでは歴史の読解に固有の点を扱う。

- 出来事の年代と、史料の成立・編纂・注釈の時期を区別する。後世の記録を同時代の直接記録として紹介しない。
- 本文、引用された別史料、編者・注釈者の評、後世の小説・演劇を区別する。何の版・翻訳・校注を読んだかと根拠箇所を残す。
- 制度や用語の解釈を研究・校注と照合し、原史料にある記述をそのまま史実全体の確定としない。OCRや訳語が判断を左右する場合は、原文・画像・別の訳等で確認し、読めない箇所を補わない。
- 中心命題に反する事例や異なる評価も探す。転載や同一資料の要約を独立した複数根拠に数えない。

## 記録・規範・解釈を分ける

「その行動をしたと記録されている」「そうすべきだと評されている」「広く行われた制度と研究されている」は別の命題として扱う。

- 忠・孝・信義などの優先順位が一律だったと仮定しない。対立する評価があるなら、その対立自体を根拠として残す。
- 例外的な逸話や理想像から、一般人の行動頻度や全時代の文化を推定しない。少数の記録は行動の可能性・当時の論点を支えても、選択確率を与えない。
- 行動だけから本心を断定しない。史料が動機を説明している場合も、その帰属を明示する。
- 記録が見つからないことと、その行動が存在しなかったことを区別する。資料間の不一致を消すために、架空の共通規則を作らない。

## 用途へ渡す

確認した社会の慣行・価値判断と、創作で採用・変更する仮定を分ける。考証だけで企画を確定しない。調査者の知識を、そのまま過去の人物が持っていた認識と同一視しない。

映像の場面レビュー、Jevの入力構築・人物表現・実験評価は、それぞれ用途側の手順が担当する。用途ごとの必須ファイルや承認工程を、この共通の読解手順へ持ち込まない。

## 返すもの

作業量に応じた短い考証メモを、利用者が指定した成果物の場所へ残す。個別案件の調査結果をスキル内へ保存しない。

| 項目 | 内容 |
|---|---|
| 判断する命題と適用範囲 | 時代・地域・立場・制度。史実か創作上の仮定か |
| 根拠と所在 | 該当箇所が何を述べるか。本文・注・評・研究・物語の区分 |
| 異なる根拠・解釈 | 反例、競合する規範、版や研究間の相違 |
| 言えること／未確認 | 個別記録から一般化できる範囲、確認できなかった点 |
| 用途への引継ぎ | 根拠の適用条件、創作上の採用・変更点、残る仮定 |
| 仮説と実測 | 次に比べる条件と、すでに観察した結果を分離 |

このスキルだけを使う作業に、Jevや映像制作の工程を追加しない。
