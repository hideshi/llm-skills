# 道具の資料の一覧

[SKILL.md](../../SKILL.md) の手順で使う、CAD の道具ごとの資料。資料には、確かめた版、確かめた日、公式の資料の所在を書き、手元で動かして確かめたこと（【実行】）と、資料で読んだだけのこと（【資料】）を分ける。

## 資料のある道具

| 道具 | 資料 | 雛形 | 確かめた版 |
|---|---|---|---|
| FreeCAD | [freecad.md](freecad.md) | [freecad_build.py](../../templates/freecad_build.py) | 1.0.0 |

## 資料の無い道具を使うとき

OpenSCAD、CadQuery、build123d など、資料の無い道具を使うときは、次の観点を公式の資料と手元の版で確かめてから使う。確かめた点は、この一覧に新しい資料として足す（確かめた版・日・印を付ける）。確かめていない関数やオプションを、記憶から書かない。

| 観点 | 確かめること |
|---|---|
| 版と入れ方 | 手元の版を命令で出す方法。案件で版を固定するか |
| 流し方 | 画面を出さずにスクリプトを流す命令。失敗したときに終わりの値が 0 以外になるか（例外で止まっても 0 で終わる道具がある） |
| パラメータ | 値を一か所に集める書き方。命令の引数や別のファイルから値を渡せるか |
| 形状の表し方 | 境界の表現（B-Rep）を持つか、メッシュや CSG だけか。持たない道具では、B-Rep の検査をメッシュの検査で代え、その旨を記録に書く |
| 作った後の検査 | ソリッドの個数、閉じているか、正しいか、を確かめる手段。無ければ、書き出したメッシュを別の道具で確かめる |
| メッシュの検査 | 閉じている、非多様体、自己交差を確かめる手段（道具の中か、別の道具か） |
| 書き出し | STEP、STL、3MF のどれを書けるか。単位が mm で出るか |
| プレビュー | 断面や外形の画像を、画面を出さずに作れるか |
| 開いたときの見え方 | 保存したファイルを道具の画面で開いたときに、部品が表示され、全体の見える視点になるか |
| 落とし穴 | 版で変わった書き方、浮動小数の誤差で面が残る、などの経験 |

## 資料の書式

- 頭に、確かめた版、確かめた日、公式の資料の所在を書く。
- 本文は、決まりを守るのに要る最小限（流し方、パラメータの持ち方、検査、書き出し、見え方、落とし穴）にする。公式の手引きを写さない。
- 案件の名前、利用者の環境に固有の場所、特定の機械の設定は書かない。
