# 既存のデータの規則違反を監査する

規則があっても、データが正しいとは限らない。実データを真実として、規則ごとに違反を数え、違反がシステムにどんな害を与えるかを試験で確かめる。データもコードも直さない。

## 入力

| 型 | 必須 | 使い方 |
|---|---|---|
| 業務規則の一覧 | 必須 | 監査する規則 |
| 改修の範囲 | 必須 | 対象の機能と、データの範囲 |
| 原典の参照 | 任意 | データの複製の所在と、個人情報の扱いの決まり |

型の中身は [型の一覧](../dev-shared/references/artifact-types.md) を見る。

隔離した複製のデータを使う許可が無いときは、問い合わせを作るところまでで止め、流さずに返す。

## 出力

| 型 | 中身の補足 |
|---|---|
| 問題台帳 | 違反ごと。規則の識別子、違反の分類、失敗のしかた、件数、確認の水準は「実行」 |
| 検証の記録 | 問い合わせ、カナリアの結果、違反0件の確認 |
| テストケース表 | 違反を再現する実証のケース。対照のケースと対にする |
| 変更の事実 | 条件付き。依頼者が試験のコードを残すと決めたとき（足した試験のファイルだけ） |

## 使わない場面

- 規則を決める、コードから規則を抜き出す。
- データやコードを直す（直すのは是正の仕事）。
- これから足す制約や新しい列について、既存のデータが破るかを設計の中で確かめる（それはデータの設計の仕事。ここで扱うのは、今ある規則を今のデータが守っているか）。

## 手順

### 1. 場所を用意する

- 既存のデータベースとは別に、隔離した複製を用意する。分析のための表を作る以外は書き込まない。
- 本番のデータに直接流さない。数える問い合わせ（読み取りだけ）を本番に流すのは、人が許したときだけ。違反のデータを入れる試験は、本番では行わない。結果に個人名や企業名などの具体値を出さない。
- 本番の資格情報（データベース、外部サービス、メールの送信など）を使わない。複製には実在の宛先が残るので、システムを動かす前に、外部への送信（メール、通知、外部の API、Webhook）を捕まえる設定にしたことを確かめる。

### 2. 検出する

- 規則1つに問い合わせ1つ。期待は「0件」。
- 分類: 構造（参照の欠け、重複）、値の範囲、項目どうしの依存、画面だけで守っている規則、基準のデータとの整合。
- 分布を見る規則は、前回の値との差で見る。
- カナリア: 既知の違反を一つ再び検出できることで、問い合わせが動いていることを確かめる。

### 3. 仕分ける

- 違反を3つに分ける: 基準のデータの値、前提の崩れ（そもそも規則の前提が成り立たない）、取引のデータ。
- 推定は必ず実測で確かめる（「この型は範囲外を拒むはず」などを、実際に流して確かめる）。

### 4. 害を確かめる

違反のデータを入れたときの失敗のしかたを4つに分ける。システムを動かすのは、手順1の隔離した場所だけで、外部への送信を捕まえた状態で行う。

| 失敗のしかた | 危なさ |
|---|---|
| 例外で止まる | 気づける |
| 検証で拒む | 気づける |
| 静かに汚染する（誤った値が保存される） | 気づけない。最も危ない |
| 機能が黙って無効になる | 気づけない。最も危ない |

- 試験にするかを判定する。しないものも、理由を付けて記録する。
- 実証の試験では、本番のデータを参照せず、同じ値を作って再現する。再現の元（表、キー、値、見つけた日）を書く。
- 異常値の試験には、必ず正常値の対照の試験を並べる。
- 例外なら種類まで、汚染なら保存された値を直接確かめる。仮説と違う動きをしたら、それ自体が発見。
- 実証の試験は、テストケース表として渡す。試験のコードを案件のリポジトリに残すかは、依頼者に確かめる。残すときは、試験のファイルだけを足し、製品のコードは直さない（直すのは是正の仕事）。残さないときは、検証の記録に試験の手順と結果だけを残す。

### 5. 運用に渡す

- 問い合わせを、データを入れ替えるたびに流し直せる形で残す。
- 是正の作業の前の関門（違反が0件であること）にも使えるようにする。

手順の根拠と、先行の手法から変えたところは [根拠と変えたところ](references/grounding.md) を見る。

## 終了条件

- すべての対象の規則に、問い合わせと件数（0件を含む）がある。カナリアが検出できている。
- 違反ごとに、分類、失敗のしかた、件数がある。静かな汚染と機能の無効化は、実証の試験か、試験にしない理由がある。
- 出力に個人の具体値が無い。
