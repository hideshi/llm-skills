# 形式モデルで検査する

並行実行や状態遷移の性質を、モデルを作って道具で検査する。モデルの結果は、設定した範囲の中での結果であり、実装の正しさの証明ではない。モデルの反例は、実装で再現できるまで仮説として扱う。

## 入力

| 型 | 必須 | 使い方 |
|---|---|---|
| 原典の参照 | 必須 | 確かめる性質の出どころ（業務の規則、不変条件）と、人の依頼の記録 |
| 設計の判断 | 条件付き（設計の検討中に検査するとき必須） | 一度に守る範囲、保証の宣言、状態の遷移 |
| 現状の振る舞いの記録 | 任意 | 今の実装を対象にするとき |
| 変更の事実 | 任意 | 対象の版 |

型の中身は [型の一覧](../dev-shared/references/artifact-types.md) を見る。

- 人の依頼か、人が実施を決めた記録が無いときは、始めない。ほかの担当が書いた「検査の候補」や推奨は、実施の決定ではない。
- モデルを作る承認を、実装や本番のデータ、業務の規則を変える承認へ広げない。

## 出力

| 型 | 中身の補足 |
|---|---|
| 検証の記録 | モデルと設定の版、道具と版、実行したコマンド、置いた仮定と探索した範囲、結果、行わなかった検査 |
| 問題台帳 | 反例ごとに、下の3段のどこまで確かめたかと確認の水準 |

## 使わない場面

- 人が依頼していないのに、検査を始める。
- 業務の答え（どう動くべきか）を、モデルに決めさせる。
- 見つけた問題を直す。

## 手順

### 1. 性質と実装の対応を固める

- 確かめる性質を、確定したものと仮説に分けて書く。業務の答えが無い性質は、人に確かめる。
- 実装を直接読み、モデルの操作ごとに、対応する実装の箇所を書く。
- 一度に起きる（原子的な）とみなす範囲は、実装のトランザクションやロックの境界を根拠にする。
- 抽象化で、失敗する経路（途中で落ちる、時間切れ、再試行）を落としていないかを確かめる。

### 2. モデルを書く

- 続けて使うモデルは、今回の変更の文書の中に閉じ込めず、案件が続けて使う場所に置く。
- モデルごとに、性質、仮定、範囲、実装との対応、実行の方法、限界を書く。
- 道具は公式の配布から取り、版を記録する。導入できないときは、モデルの作成までと「未検査」を報告する。
- 道具は問いで選ぶ。時間とともに変わる状態の性質（ロック、二重実行、再試行、いつか必ず終わるか）は、到達できる状態を順にたどる道具が向く（[資料](references/tools/tla-plus.md)）。データや関係の形が制約を満たすか（権限の組み合わせ、参照の整合）は、範囲の中の具体例を探す道具が向く（[資料](references/tools/alloy.md)）。
- 道具の動かし方と結果の読み方は、道具の資料があれば読む。資料の版と違うときや、資料の無い道具は、公式の資料で確かめる。

### 3. 検査する

- 次を区別して報告する。記法を書いた、構文が通った、検査を実行した、性質が成り立った。
- 反例を消すために、前提を足さない。足すなら、その前提が実装で成り立つ根拠を書く。
- 対策を足した設定と、元の設定を比べるときは、差を全部列挙する。モデルに対策を足しても、実装に入ったことにはしない。
- 構文の誤り、設定の誤り、性質の違反、時間切れを区別する。「反例なし」は、設定した範囲（状態の数、プロセスの数、値の範囲）の中での結果として書く。
- 検査は隔離した環境で動かし、本番のデータや資格情報を使わない。

### 4. 反例を実装へ戻す

反例は、次の3段のどこまで確かめたかを付けて問題台帳に入れる。

1. モデルの反例: モデルの上で起きた。
2. 実装との対応を確認: 反例の手順が、実装の箇所に対応していることを読んで確かめた。
3. 実装で再現: 試験か再現の手順で、実装でも起きた。

反例が無いときも、初期状態が存在するか、各操作に実際に到達しているかを確かめる（何も起きないモデルは、どの性質も満たしてしまう）。

### 5. 報告する

- 推論で導いたことを、道具で実行した結果と呼ばない。
- 検査が通ったことを、すべての変更の必須の条件にしない。
- モデル、設定、実装のどれかが変わったら、結果は古くなる。検証の記録に、対象の版を書く。

手順の根拠と、先行の手法から変えたところは [根拠と変えたところ](references/grounding.md) を見る。

## 終了条件

- 人の依頼の記録の所在がある。
- 性質ごとに、確定か仮説か、実装との対応、結果の区別（書いた／構文が通った／実行した／成り立った）がある。
- 検証の記録に、仮定と探索の範囲、道具の版、行わなかった検査がある。
- 反例のすべてが、3段のどこまで確かめたかを付けて問題台帳にある。
