# 名前だけを取り出す

[SKILL.md](../../SKILL.md) の手順1で、設定のファイルからキーの名前だけを取り出すときの作り方。担当がファイルを開かず、出力に値が一つも出ないことを、取り出し方で保証する。

## 決まり

- 出力するのは、名前の形に合う部分だけ。行全体を出さない。
- 名前の形に合わない行は、中身を出さずに件数だけを数える。件数が0でなければ、その形式は「見本で確かめていない形式」として扱い、人に値の無い一覧を頼む。
- 先に、作り物の値だけを入れた見本のファイルで流し、出力に作り物の値が一つも出ないことを確かめる。見本には、複数行の値、引用符の中の `=`、コメント、空の値、行の途中の `export` を入れる。
- 誤りの表示（解析の失敗、読めないファイル）に、行の中身を出さない。

## `NAME=value` の形の設定（例）

```bash
(
  set -uo pipefail
  f="${1:?対象のファイルを指定する}"
  # 名前の形に合う所だけを出す（行全体は出さない）
  grep -oE '^[[:space:]]*(export[[:space:]]+)?[A-Za-z_][A-Za-z0-9_]*=' -- "$f" \
    | sed -E 's/^[[:space:]]*(export[[:space:]]+)?//; s/=$//' | sort -u
  # 合わない行は数だけ（空行とコメントを除く）
  n=$(grep -vcE '^[[:space:]]*(#|$|(export[[:space:]]+)?[A-Za-z_][A-Za-z0-9_]*=)' -- "$f" || true)
  echo "名前の形に合わない行: ${n}"
)
```

- 2026-11-14 に、Bash 5.2.37 と GNU grep で、作り物の値（コメントの中の値、`=` を含む引用、空の値、`export`、行頭の空白、3行の鍵の本文）の見本に流し、出力が名前の5つと「合わない行: 2」だけで、作り物の値が一つも出ないことを確かめた。
- `grep -o` は、当たった部分だけを出す。行全体を出す `grep` や、区切りの無い行をそのまま出す切り出し（`cut -d= -f1` など）は使わない。複数行の値（鍵の本文など）の続きの行が、そのまま出てしまう。
- 「名前の形に合わない行」が0でないときは、複数行の値か、知らない形式が混ざっている。その形式は取り出さずに止める。
- この例は、`NAME=value` の形で一行に一つの代入の設定だけを対象にする。YAML、JSON、TOML などは、その形式の解析の道具で、キーの名前だけを出す方法を同じ決まりで作り、見本で確かめてから使う。

## 直書きを探すとき

- 当たった行を出さない。`grep -l`（当たったファイルの名前だけ）か `grep -c`（件数だけ）を使う。
- 名前を知りたいときは、`grep -o` で名前の形の部分だけを出す。値の形（長い英数字の並びなど）を表示する検索はしない。
