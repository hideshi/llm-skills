# 公開面の画面

認証の無い利用者に向けた画面（訴求のページ、短いタスクを終える道具）で、画面の設計に足すこと。

## 共通仕様に足すこと

- 親のサイトとの関係（移動の項目を写さない、どこへ戻るか）。
- 見た目の調子（親のサイトと同じか、柔らかくするか）。値はデザインシステムの判断に任せる。
- 公開の言葉と業務の用語の対応の表（文言の決まりを見る）。

## 画面ごとに足すこと

| 項目 | 書くこと |
|---|---|
| 主な操作 | 画面ごとに1つ。同じ操作を上と下に重ねて置かない |
| 最初の表示 | 決めた幅（例: 案件が決めた PC とスマートフォンの幅）で、主な操作がスクロールせずに見えるか。見えなければ固定の置き場所 |
| 入力の保持 | 誤りを直すときに、入れた値を消さない。保持するなら、保存場所・期間・削除を設計の判断へ返す |
| 同意と規約 | 個人の情報を受け取る画面には、同意と、規約・運営者への導線 |
| 計測点 | 何を数えるか（主な操作の押下、入力の完了）。計測の実装は範囲外 |
| 状態 | 通常、入力の誤り、システムの失敗（問い合わせの導線つき）、読み込み中（時間がかかるとき）。権限なしは普通は要らない |

最初の表示で見えるかは、受入条件の案として返す（どの幅で、何が見えるか）。確かめ方（表示の大きさを決めて、要素が表示の範囲に入っているかを見る）は、受入の試験の側で決める。

## 範囲外

- 検索エンジン向けの情報、共有のための情報、比較の試験の設計、計測の実装。
- 規約や同意の文の中身（法的な判断を含む）。
