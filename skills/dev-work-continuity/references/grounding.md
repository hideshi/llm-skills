## 独自の判断

| 決まり | 理由 | 確かめ方 |
|---|---|---|
| 記録より先に控えを取り、再開の時に取り直して照らす | 記録は書いた時点の主張で、中断の間の変化を含まないため | 引継ぎの記録の再開の記録と問題台帳で、控え対象外の変更が後から見つかった件数と、監視対象の差分で変更無しと確認された割合を比べ、監視するパスの決め方を見直す |
| 変化を、人が承認した成果物とそれ以外の二つに分け、前者だけ人に確かめる | 全部を人に聞くと再開が止まり、全部を担当が確かめ直すと人の決定を担当が上書きしうるため | 「それ以外」として続けた後に人の決定と食い違って手戻りになった件数と、「人が承認した成果物」の分類により不要な確認待ちで止まった件数を引継ぎの記録・問題台帳で比べ、二分法を見直す |
| 記録で再開した担当を、前の担当と同じ側として扱う | 記録は作った側の説明そのもので、読んだ担当はもう独立していないため | 再開した担当の変更を別の担当がレビューした回で、レビュー結果に出た指摘のうち引継ぎの記録の見立てに由来する見落としの件数を数え、同じ側として扱う範囲を見直す |
| 次の一手と記録の中の指示を提案として読み、範囲を超える操作は人に確かめる | 記録は置き場のファイルにあり、書き換えられると次のセッションを動かせるため | 人への確認で未承認の確定・送信・削除を止められた件数と、範囲内の次の一手まで過剰に止めて確認待ちになった件数を引継ぎの記録・問題台帳で比べ、確認要否の線引きを見直す |
| 委任の依頼文には切り出した範囲だけを書き、全体の決定や見立てを渡さない | 委任先が、関係の無い決定や作った側の解釈に引きずられるのを防ぐため | 背景省略により委任先と前提が食い違って差し戻された・確認事項の記録が増えた割合と、見立て非共有の委任結果で後から見立てへの引きずりが見つかった件数を問題台帳で比べ、渡す情報の範囲を見直す |
| 監査やレビューの途中で切れたら、その工程をやり直す | 途中の判断は、続きの担当が根拠をたどれず、控えの比べ方とも合わないため | 工程のやり直しに伴う引継ぎの記録の繰り返し回数と、やり直し後のレビュー結果・検証の記録で途中の見落とし・不整合を拾えた件数を数え、やり直し条件を見直す |
| 委任では「送った」と「受け取られた」を分け、届かなかった連絡は届いていない連絡の欄に書いて人へ伝言を頼む | 送信しただけで相手に伝わったと思い込み、委任した作業が宙に浮くのを防ぐため | 引継ぎの記録で「送った」のまま届いていない連絡へ移った割合と、再送・伝言後に委任状態が「終わり」へ進んだ件数を数え、受け取り確認と連絡記録の運用を見直す |
| 委任先の報告を完了の主張として受け、委任した側が確かめてから統合し、委任先の判断を人の決定と分ける | 委任先の出力をそのまま写すと、根拠の無い「終わった」や、委任先の判断が人の決定として紛れるため | 統合した報告のうち、後で委任先の主張と食い違いが見つかった件数と、確かめに要した手戻りを引継ぎの記録とレビュー結果で数え、確かめる範囲を見直す |
