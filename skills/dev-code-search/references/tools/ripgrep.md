# ripgrep

本文の手順（範囲と除いた所を書く、言い換えで探す、件数で当たりを付ける、無いことを断定しない）を、ripgrep（`rg`）で行うときの資料。

- 確かめた版: ripgrep 14.1.1、Linux
- 確かめた日: 2026-11-13
- 【実行】は小さなリポジトリを作って実際に動かして確かめたこと、【資料】は公式の資料で読んだだけのこと

## 既定で外れる所

**ripgrep は、既定で次を黙って外す。外れたことは出力に出ない**（【実行】）。

| 外れるもの | 確かめたこと | 含めるとき |
|---|---|---|
| 版管理の無視の設定（`.gitignore` など）に当たるファイル | Git のリポジトリの中では、`build/`、`vendor/` に書いた名前が出なかった。リポジトリの外では `.gitignore` が効かず、`build/` の中も当たった | `--no-ignore`（`-u`） |
| 隠れたファイルとディレクトリ（`.` で始まる） | `.github/` の設定に書いた名前が出なかった | `--hidden`（`-uu` は無視の設定と隠れたファイルの両方） |
| 中身がバイナリのファイル | 【資料】NUL の文字を含むファイルを、既定で外す | `--binary`（`-uuu` は上の二つと `--binary`）。ただし出るのは `binary file matches` の1行だけで、当たった行は出ない（【実行】）。行を見るには `-a`（`--text`） |
| シンボリックリンクの先 | 【資料】`-uuu` でもたどらない | `-L`（`--follow`） |

- 生成物や取り込んだ依存を外すのは、名前の分からない概念を探すときには妥当なことが多い。波及の問いと「無いことの確かめ」では、外したまま「見つからなかった」と書かない。`-uu` で探し直すか、外した範囲を記録に書く。
- 【実行】版管理に入れていない新しいファイルは、無視の設定に当たらなければ探す。
- 探した範囲そのものは `rg --files`（`-uu` も付けられる）で一覧にできる。

## 文字コード

- **既定は UTF-8 として読む。Shift_JIS のファイルにある日本語は、日本語で探しても見つからない**（【実行】0件で、誤りも出ない）。古いシステムでは、`file` などで文字コードを先に確かめる。
- `-E sjis`（`--encoding`）を付けると Shift_JIS のファイルの日本語が見つかる。**ただし全部のファイルをその文字コードで読むので、今度は UTF-8 のファイルの日本語が見つからなくなる**（【実行】）。文字コードごとに分けて2回探す。英数字だけの言い換えは、どちらでも見つかった。

## 言い換えと絞り込み

| したいこと | コマンド（【実行】） |
|---|---|
| 言い換えをまとめて探す | `rg -e shipOrder -e 発送 -e shipment src` |
| 大文字と小文字を区別しない | `rg -i shiporder` |
| 語として当たるものだけ | `rg -w ship`（`shipOrder` には当たらない） |
| 正規表現を使わず文字どおり | `rg -F 'price(1.1)'` |
| ファイルの種類で絞る | `rg -t php 発送`。種類の中身は `rg --type-list` で見る |
| 当たったファイルの一覧 | `rg -l shipOrder` |

- 【実行】`-t js` には `.vue` も入るが、`-t ts` には入らない。種類で絞るときは、中身を `--type-list` で確かめる。
- 【実行】知らない種類の名前を `-t` に渡すと、`unrecognized file type` で終了コード2になる。

## 件数

- **`-c` は、当たった行の数を出す。1行に2回出ても1と数える**（【実行】）。当たった回数は `--count-matches`。
- 波及の大きさを件数で見積もるときは、どちらで数えたかを記録に書く。

## 終了コード

| 終了コード | 意味（【実行】） |
|---|---|
| 0 | 1件以上当たった |
| 1 | 1件も当たらなかった |
| 2 | 誤りがあった（知らない種類、読めない場所など）。探索は止まらず、ほかの場所の当たりは出たうえで2になる |

- 1 と 2 を分けて読む。2 のときは、読めなかった場所を記録の「除いた範囲」に書き、そこで「見つからなかった」と書かない（【実行】無い場所を混ぜて探すと、当たりを出したうえで終了コード2になった）。
- 出力を `head` などにつなぐと、シェルが見る終了コードはつないだ先のものになる。
