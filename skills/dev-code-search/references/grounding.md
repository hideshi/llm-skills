## 独自の判断

| 決まり | 理由 | 確かめ方 |
|---|---|---|
| 索引や意味の検索の結果は候補にとどめ、今のソースで開いたものだけを静的と書く。索引の版が今のソースと違えば使わない | 索引は作った時点の写しで、消えた・移ったコードを返しうるため | 索引の結果を候補とした問いで、後の工程に今のソースに無い所在が持ち込まれた件数を数え、索引の扱いを見直す |
| 探した範囲と除いた範囲（道具が既定で外す所、別のリポジトリ）を記録の冒頭に書く | 検索の道具は既定で生成物や隠れたファイルを黙って外し、「無い」の誤りの元になるため | 除外範囲の見落としで後から別箇所が見つかった誤判定件数と、対象範囲を明示した調査での再調査発生率を現状の振る舞いの記録や後続のレビュー結果（や案件の問題台帳）で追い、範囲記載を見直す |
| 見つからなかったときは「無い」と断定せず、試した言い換えと範囲を書く | 0件は、無いことと、探し方が足りないことを区別できないため | 「この範囲では見つからなかった」とした問いで、後から範囲の内か外に実装が見つかった件数を記録し、言い換えの作り方と範囲の決め方を見直す |
| 推測した英語名は検索の種にだけ使い、記録には確かめた名前だけを書く | 推測の名前が記録に残ると、後の工程でそれが実在の名前として扱われるため | 記録に残った未確認の推測名で後の実装・検索が空振りした件数を記録し、推測名の扱いを見直す |
| 実装が意図どおりかはここで決めず、推測の欄に書く | 場所を探す仕事と、振る舞いの正しさを判断する仕事を分け、軽い問いに重い調査を持ち込まないため | 場所を探す依頼が、振る舞いの調査や問題の台帳づくりまで広がった回と、その分の手戻りを記録し、境界の書き方を見直す |
