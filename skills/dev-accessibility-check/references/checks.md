# 基準と確かめ方

WCAG 2.2 の A と AA の達成基準（A 31、AA 24。4.1.1 は 2.2 で削除）ごとに、主な確かめ方と、よくある見落としを並べる。基準の正本は WCAG 2.2 の本文で、ここは点検の段取りのための目安。基準の名前は英語の正式名を添え、日本語は意味を短く言い換えたもの。

確かめ方の略: 自動＝自動の点検、操作＝担当の操作、人＝人の手順。並べた順に頼る。自動だけで「合格」にできる行は無い。

## A

| 番号 | 基準（英語の名前） | 主な確かめ方 | よくある見落とし |
|---|---|---|---|
| 1.1.1 | 文字でない内容に代わりの文がある（Non-text Content） | 自動、人 | 代わりの文が有るかは自動で分かるが、内容を表すかは人が採る。飾りの画像に文を付けすぎる |
| 1.2.1 | 収録済みの音声だけ・映像だけの代替（Audio-only and Video-only (Prerecorded)） | 人 | 面が無ければ該当なし |
| 1.2.2 | 収録済みの字幕（Captions (Prerecorded)） | 操作、人 | 字幕の有無は操作、正しさは人 |
| 1.2.3 | 音声の解説か、メディアの代替（Audio Description or Media Alternative (Prerecorded)） | 人 | |
| 1.3.1 | 情報と関係が構造で伝わる（Info and Relationships） | 自動、操作 | 見た目だけの見出しや表。入力欄のまとまり（fieldset）の欠け |
| 1.3.2 | 意味のある順序（Meaningful Sequence） | 操作 | 並べ替えた配置で、読む順と見た目の順がずれる |
| 1.3.3 | 形や位置だけで指示しない（Sensory Characteristics） | 人 | 「右の緑のボタン」のような文言 |
| 1.4.1 | 色だけで区別しない（Use of Color） | 操作 | 誤りの入力欄を赤い枠だけで示す。本文の中のリンクを色だけで示す |
| 1.4.2 | 自動で鳴る音を止められる（Audio Control） | 操作 | |
| 2.1.1 | キーボードで操作できる（Keyboard） | 操作 | クリックだけに反応する要素、ドラッグだけの操作 |
| 2.1.2 | キーボードの閉じ込めが無い（No Keyboard Trap） | 操作 | 埋め込みの部品からフォーカスが出られない |
| 2.1.4 | 1文字のショートカットを止められる（Character Key Shortcuts） | 操作 | |
| 2.2.1 | 時間の制限を調整できる（Timing Adjustable） | 操作 | ログインの時間切れの予告が無い |
| 2.2.2 | 自動で動くもの・更新されるものを止められる（Pause, Stop, Hide） | 操作、自動 | 自動で始まり5秒を超えて動き、他の内容と並ぶもの（カルーセル、流れる文字）。自動で更新される情報（件数、状況の表示）は5秒の条件なしで、止める・隠す・頻度を変える手段を見る。欠かせないものは例外 |
| 2.3.1 | 1秒に3回を超えて光らない（Three Flashes or Below Threshold） | 操作、人 | |
| 2.4.1 | 繰り返しの部分を飛ばせる（Bypass Blocks） | 自動、操作 | 見出しや目印の領域が無く、飛ばす手段が無い |
| 2.4.2 | 頁の題がある（Page Titled） | 自動、人 | 画面を移っても題が変わらない一枚の頁のアプリ |
| 2.4.3 | フォーカスの順序（Focus Order） | 操作 | ダイアログを閉じた後に先頭へ戻る |
| 2.4.4 | 文脈からリンクの目的が分かる（Link Purpose (In Context)） | 自動、人 | 「こちら」「詳しく」だけのリンク |
| 2.5.1 | 複数の指の操作や軌跡に代わりがある（Pointer Gestures） | 操作 | |
| 2.5.2 | 押して離したときに動き、取り消せる（Pointer Cancellation） | 操作 | 押した瞬間に確定する |
| 2.5.3 | 見えるラベルが名前に含まれる（Label in Name） | 操作 | 見えるラベルと、木の名前が違う |
| 2.5.4 | 端末を動かす操作に代わりがある（Motion Actuation） | 操作 | |
| 3.1.1 | 頁の言語（Language of Page） | 自動、人 | 言語の指定が有るか・形が正しいかは自動で分かるが、本文の主な言語と合うかは人（か担当の目視）で確かめる |
| 3.2.1 | フォーカスしただけで文脈が変わらない（On Focus） | 操作 | |
| 3.2.2 | 入力しただけで予告なく文脈が変わらない（On Input） | 操作 | 選んだだけで画面が移る選択欄 |
| 3.2.6 | 助けの場所がそろう（Consistent Help） | 操作 | 範囲の画面の間でだけ見る。全体は範囲外と書く |
| 3.3.1 | 誤りを特定して文字で伝える（Error Identification） | 操作 | 誤りを色だけで示す。どの欄の誤りかが木で伝わらない |
| 3.3.2 | ラベルか説明がある（Labels or Instructions） | 自動、操作 | 入力の形の決まり（桁数、書式）が書かれていない |
| 3.3.7 | 同じ入力を繰り返させない（Redundant Entry） | 操作 | 手続きの途中で前に入れた値をもう一度求める |
| 4.1.2 | 名前、役割、値が伝わる（Name, Role, Value） | 自動、操作 | 自作の部品の開閉や選択の状態が木で伝わらない |

## 水準より上と、案件の要件

- 目標の水準より上の基準（例: 2.3.3 操作で起きる動きを止められる、AAA）と、案件が独自に決めた要件は、別の水準の行として基準の判定の表に足す。
- 動きを減らす設定（prefers-reduced-motion）への対応は、2.3.3（AAA）に当たる。AA の目標では、案件が決めたときだけ行にする。
