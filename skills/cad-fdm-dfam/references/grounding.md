# 根拠と変えたところ

## 独自の判断

| 決まり | 理由 | 確かめ方 |
|---|---|---|
| 手引きの数値を確定値にせず、試し刷りの振り幅の中心に使う | 手引きの数値は、ノズル径、素材、機種、設定を前提にしていて、手引きどうしでも違う（たとえば最小の肉厚は 0.5 mm とノズル径以上、すきまは 0.3 mm と 0.6 mm） | 試し刷りで決めた値と、手引きの目安の差を記録し、前提ごとの差を見る |
| 柔らかさはまず形で作り、インフィルの率は補いにする | 素材の会社も、刷った部品の柔らかさは設定で変わると書いている。設定に頼ると、刷る人や道具が変わると再現しない | 同じ形で、設定を変えたときの柔らかさの差を試し刷りで見る |
| 閉じた空洞に空気の逃げる穴を設け、接着やテープでふさがない所に置く | 確かめた手引きには書かれていない。押したときの空気の逃げ場が無いと、狙った柔らかさが出ない、という設計の考え方 | 穴の有無と位置を変えた試し刷りで、押したときの沈みと戻りを比べる |
| 圧入の内壁に接着剤の逃げる溝、入口に挿入を導く面取り、二重の嵌合 | 確かめた手引きに数値や作り方は無い。入口でのしごき取りと空気のかみ込みを避ける設計の考え方 | 溝と面取りの有無を変えた試し刷りで、入れる力と抜ける力、接着剤の回り方を見る |
| 彫り文字の線の太さは押し出しの幅の2本分以上を出発点にする | 確かめた手引きに数値は無い。最小の肉厚の考え方（1本では細い形が刷れない）から出発点を置く | 深さと線の太さを振った試し刷りで読めるかを見る |

## 改善の記録

- 2026-11-15: 初版。Prusa の記事4本と、UltiMaker の記事と設計の手引き（PDF）、Polymaker の TPU の頁を開いて確かめた。Bambu Lab の頁は開けず、根拠にしていない。彫り文字の深さ、圧入の締め代、接着の溝、空洞と空気の逃げは、公式の手引きで数値を確かめられなかったので、【判断】と試し刷りの手順にした。
