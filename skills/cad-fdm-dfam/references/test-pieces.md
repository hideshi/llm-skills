# 試し刷り

[SKILL.md](../SKILL.md) の手順4で、プリンタと素材で変わる値を、試し刷りの実測で決めるときの形。

## 決まり

- 本体と同じプリンタ、ノズル径、層の高さ、素材、設定、向きで刷る。どれかを変えたら、その値は本体には使えない。
- 本体の形から、決めたい所だけを小さく切り出す。全体を刷り直さない。
- 一つの試し刷りで、値を段階的に振った列を刷る（例: すきまを 3〜5 段）。振り幅の中心には、手引きの目安を使う。目安が無ければ、設計の判断で置き、そう書く。
- 測るときは、何を、何で（ノギス、すきまゲージ、実物の相手の部品）、何回測ったかを書く。合否は、決めておいた基準で判定する（「入るか」「抜けるか」「手で押して戻るか」など）。
- 決めた値は、根拠の種類を「試し刷りの実測」にし、刷った日、前提、測った結果とともに記録する。一次情報の記録とは分けて書く。

## 計画の形

値ごとに次を書く。

| 欄 | 中身 |
|---|---|
| 決める値 | パラメータの名前（例: 差し込みのすきま） |
| 刷るもの | 切り出す形と、振る値の列 |
| 前提 | プリンタ、ノズル径、層の高さ、素材、設定、向き |
| 測るもの | 寸法、入るか、抜ける力、押したときの戻り など |
| 決め方 | 合否の基準と、どの段を選ぶか |
| 安全に関わるか | 関わるなら、本体の試作でも確かめる |

## よく使う試し刷り

- **すきまと嵌め合い**: 相手の部品（または同じ寸法の作り物）に入る穴か軸を、すきまを段階的に振って並べる。入るか、がたつくか、抜ける力を見る。
- **圧入と締め代**: 穴の径を、相手より小さい側に段階的に振る。入れる力、割れ、抜ける力を見る。素材の硬さで大きく変わるので、素材ごとに刷る。
- **オーバーハングとブリッジ**: 角度か長さを段階的に振った小片。垂れ、面の荒れを見る。
- **浮き文字・彫り文字**: 深さと線の太さを振った小片。読めるか、潰れていないか、最初の層に入れるなら定着を見る。
- **柔らかさ**: 空洞の大きさや壁の厚さを振った小片。決めた力で押したときの沈みと戻りを見る。押し方（指、重り、測る道具）と回数を決めておく。
