# FDM で造形する部品の形を決める

熱で溶かした樹脂を層ごとに積む造形（FDM）で、部品が破綻せず、狙った嵌め合いと硬さが出る形を決める。形の方針の案と、落とし穴の点検と、試し刷りの計画を作り、人が方針を決める材料にする。

## 入力

| もの | 必須 | 使い方 |
|---|---|---|
| 何を作るか | 必須 | 部品の役目、相手の部品、かかる力の向き、見た目の要求 |
| 造形の前提 | 必須 | プリンタ、ノズル径、層の高さ、素材と硬さ（Shore など）、冷却の仕方。分からない所は「未確認」として受ける |
| 形の案 | 任意 | スケッチ、寸法の案、今あるモデル |
| 一次情報の記録 | 任意 | 素材のデータシート、相手の部品の寸法、ルールの値（項目の識別子で指す） |
| 実測の値 | 任意 | 試し刷りや試作を測った値 |

- 造形の前提のうち、プリンタ、ノズル径、素材が分からないときは、目安を当てはめずに止め、依頼者に聞く。目安はこの3つで大きく変わるため。

## 出力

- **形の方針の案**: 造形の向き、支えの要否、論点ごとの扱い（下の手順3）、パラメータの名前と値と、値の根拠の種類（手引きの目安／試し刷りで決める／設計の判断／一次情報の記録の項目）。
- **落とし穴の点検の結果**: 論点ごとに、当たる・当たらない・未確認と、当たるなら形での手当て。
- **試し刷りの計画**: 条件で決まる値ごとに、刷るもの、刷り方、測るもの、決め方。[試し刷り](references/test-pieces.md)の形に従う。

方針を決めるのは人。この単位は案と、それぞれを選んだときの影響を返す。

## 使わない場面

- 3D モデルのスクリプトを書いて組み立て、検査し、書き出す（パラメトリックに形を作る、別の仕事）。
- 素材、競技や規格のルール、市販品の寸法の値を確かめる（一次情報の記録を作る、別の仕事）。
- スライサーの設定だけを調整する（形を変えない調整）。設定に頼らないと出ない性質は、形での手当てを先に考える。
- 光造形（SLA）、粉末の造形、射出成形など、FDM 以外の作り方。

## 決まり

1. **目安は前提条件つきで使う**: 手引きの数値は、そのノズル径・層の高さ・素材・機種での目安。前提が違えば当てはめず、試し刷りで決める。数値を確定値として書かない。
2. **形で作れるものは形でも作る**: スライサーの設定（インフィルの率など）だけに頼る性質は、刷る人や道具が変わると再現しにくい。硬さ、嵌め合い、支えの要らなさは形でも作る。形で作っても設定の影響は残るので、使った設定も設計の条件として記録し、変えたら確かめ直す。
3. **条件で決まる値は試し刷りで決める**: すきま、締め代、柔らかさ、彫りの深さなど、プリンタと素材で変わる値は、試し刷りの計画にして、実測の値で決める。手引きの目安は、試し刷りの振り幅の中心に使う。
4. **根拠の種類を分ける**: 手引きの目安、試し刷りの実測、設計の判断、一次情報の記録の項目を混ぜない。値ごとに、どれかを書く。
5. **安全に関わる所は確定させない**: 防護や強度に関わる肉厚や硬さが、目安だけで決まっているなら、試作で確かめるまで「確定ではない」と書く。

## 手順

### 1. 前提を集める

プリンタ、ノズル径、層の高さ、素材と硬さ、冷却、造形できる大きさを集める。案件の指示の文書にあればそれを写す。分からない所は「未確認」と書く。ただし、プリンタ、ノズル径、素材は未確認のまま進めない（入力の決まりのとおり止めて聞く。素材を人が選ぶ段なら、候補ごとに案を分ける）。

### 2. 向きを決める

かかる力の向きと、層の間の弱さを比べて、造形の向きを決める。次の順で見る。

1. 力がかかる向きに、層の境目が並ばないか（層の境目に引っぱりや曲げがかかる向きは避ける）。
2. 支えなしで刷れる面が多いか（オーバーハングの角度）。
3. 造形台に置く面が平らで広いか、その面の縁と見た目の要求。

向きを2案まで挙げ、選んだ理由と選ばなかった理由を書く。

### 3. 論点ごとに点検する

[論点と目安](references/design-rules.md)の論点ごとに、当たるかを見て、当たるなら形での手当てを書く。論点は次のとおり。

- オーバーハングとブリッジ
- 造形台に向いた縁（面取りとフィレット）と最初の層の広がり
- 最小の肉厚と細い形
- 浮き文字・彫り文字
- 嵌め合い・すきま・圧入・接着の構造
- 柔らかい素材の硬さを形で作る構造（空洞と空気の逃げ）
- 閉じた空洞、薄い天井、支えを外せない所

### 4. 試し刷りの計画を作る

手順3で「条件で決まる」とした値ごとに、[試し刷り](references/test-pieces.md)の形で計画を書く。試し刷りの形は、本体の形の一部を切り出した小さなものにし、本体と同じ向き・素材・設定で刷る。

### 5. 方針の案にまとめる

向き、論点ごとの手当て、パラメータの値と根拠の種類、試し刷りの計画を、形の方針の案にまとめる。値は、モデルのスクリプトのパラメータとして使える名前で書く。人が決めることと、選んだときの影響を並べる。

### 6. 実測を受けて直す

試し刷りや試作の実測が来たら、値を直し、根拠の種類を「試し刷りの実測」にする。目安と違った値は、前提の違い（ノズル径、素材、設定）とともに書いておく。

手順の根拠と、先行の手引きから変えたところは [根拠と変えたところ](references/grounding.md) を見る。

## 終了条件

- 造形の前提がそろっているか、未確認の所が書いてある。
- 向きと、選んだ理由がある。
- 論点ごとに、当たる・当たらない・未確認と、当たるなら手当てがある。
- パラメータの値ごとに根拠の種類があり、条件で決まる値には試し刷りの計画がある。
- 安全に関わる値で確定でないものが、一覧になっている。
