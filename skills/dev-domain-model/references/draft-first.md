# たたき台を先に作る進め方

関係者の時間が少ないとき、業界の慣行が厚い領域のときに、対話より先にたたき台を作り、確かめる論点を全部並べてから一度に確かめる進め方。

## 1. 慣行を調べる

- 業界の慣行、公的な規則、似た製品の公開の仕様を調べ、出典ごとに大まかな段（公的な規則 > 業界団体の規格や公表 > 解説 > 推測）を付ける。公的な規則と業界団体の規格を根拠にするときは、たたき台の後に一次情報として確かめ直す（公的な規則の中の段の細かい分け方は、その裏取りの側で決める）。
- 出典の無い知識は「推測」と書く。推測を確定の根拠にしない。
- 慣行が分かれる所は、黙って一つに決めない。選択肢として並べる。

## 2. たたき台を作る

- 用語、管理するもの、状態と遷移、区分、規則を、仮説として全部書く。仮説の規則にも識別子を振り、確かさを「仮説」にする。
- 仮説の規則を、要件の根拠にしない。
- 画面の流れを確かめるために仮のワイヤー（画面の骨組み）を作るときは、仮であることを書き、規則の了承を画面で取らない。

## 3. 論点を先に全部並べる

確かめる論点を、確認事項の記録に先に全部並べる。質問文は、それだけで意味が通るように書き、備考に今の案と推測の根拠を書く。

## 4. 確かめる

- 規則ごとに確かめる。「はい」で終わらせず、具体例で言ってもらい、例外を必ず聞く。
- 回答は原文のまま記録する。人づての回答は、伝えた人も記録する。

## 5. 結果ごとの直し方

| 結果 | モデルと一覧の直し方 |
|---|---|
| 確定 | 確かさを「確定」にし、根拠に確認事項の番号を書く |
| 変更 | 規則の本文を直し、確定にする。識別子は変えない |
| 却下 | 廃止の印を付ける（番号は詰めない） |
| 一部 | 確定した部分と残りを分け、残りは新しい論点にする |
| 保留 | 関係者の了承と期限があるときだけ。期限を書く |

## 担当の裁量で確定させるとき

- 振り分けの案はこちらで作り、決めるのは名指しされた担当。名指しが無ければ任せない。
- お金・税・法令に関わるもの、後から変えると高いもの、顧客の外に見える約束は、担当に任せない。
- 担当に任せるには関係者の了承が要る。担当が確定させた一覧は、関係者に見せる。
