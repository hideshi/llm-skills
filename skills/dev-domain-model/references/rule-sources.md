# 規則の起点と確定の条件

業務規則が入ってくる起点ごとに、確定と言える条件と、根拠の書き方を決める。

| 起点 | 確定の条件 | 根拠の書き方 |
|---|---|---|
| 関係者の決定 | 関係者が具体例と例外まで確かめた | 確認事項の番号 |
| 担当の裁量 | 名指しされた担当が決め、関係者が裁量を了承している | 担当の名と了承の記録 |
| 公的な規則 | 一次情報の記録で、段と施行日が確かめてある | 基準の識別子（一次情報の記録の項目） |
| 業界の慣行 | 出典があり、関係者が採用を確かめた | 出典と確認事項の番号 |
| 外部の仕様（つなぐ相手、業界団体の規格や標準） | 一次情報の記録で確かめてある | 一次情報の記録の項目の識別子 |
| 実装で受け入れた動作 | 今の動きとして観察し、関係者が今のままでよいと確かめた（確かめていなければ仮説） | 現状の振る舞いの記録の観察 |
| 推測 | 確定にしない | 「推測」と書く |
| 不明 | 確定にしない。由来が分からない既存の規則を含む | 「不明」と書き、確認事項にする |

## ぶつかったとき

- 公的な規則が先。その範囲の中で、関係者の決定に従う。
- 関係者の決定が公的な規則と合わないときは、決定を書き換えず、決めた人に返す（確認事項にする）。
- 適用の場面が違う規則どうしは、矛盾ではない。場面を書き分ける。
