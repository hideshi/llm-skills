## 独自の判断

| 決まり | 理由 | 確かめ方 |
|---|---|---|
| 検証点の区分（保持・変更予定・回答待ち）と、区分の無い変化は回帰として扱う | 今の動きに誤りが含まれるとき、「変えてよい変化」と「壊れた変化」を検証点の単位で見分けるため | 改修後の失敗を区分だけで切り分けられず人手調査や見落としが起きた件数を記録し、区分の種類を見直す |
| 期待値を変えてよいのは、変える動きが是正の対応表・完了条件の一覧・依頼側の回答のどれかで決まっている検証点だけ | 試験を今の出力に合わせて書き換え、回帰を見逃すのを防ぐため | 変更を拒んだ検証点が後で正当な変更と判定された過剰停止件数と、誤って変えて回帰を見逃した件数を比較し、許可条件を見直す |
| 記録の無い期待値で基準を作らない | 推測の動きを基準にすると、改修前後の比較が意味を失うため | 記録が無くて基準を作れず止まった件数と、その後に人の回答で期待値が変わった割合を問題台帳・回帰の基準で追い、停止基準を見直す |
| 初期の状態から3回以上続けて通す | 結果が揺れる検証点を、基準に入れる前に見つけるため。回数は経験則で、理論の根拠は無い | 3回で見逃した揺れが後で見つかった件数を記録し、回数を見直す |
| 疑いは、正誤を判定しない観察だけの手順で記録し、道具の失敗とシステムの結果を分ける | 試験の道具の不具合を、システムの成功や拒否と取り違えないため | 道具起因の失敗をシステム結果と混同して誤った是正をした件数を記録し、切り分け書式を見直す |
| 同時に動かしたことを確かめるときは、実際に重なったことを記録し、順に動かした結果と比べる | 重なったつもりで順に動いていた結果を、排他の保証と取り違えないため | 同時実行の比較で競合や順序依存を検出した件数と、重なり確認を通した回帰の基準の後に問題台帳へ本番競合が上がった件数を数え、比較要件を見直す |
