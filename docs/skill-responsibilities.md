# 時代考証スキルの責務と共通化の第一段階

2026-11-02。新設した `historical-context-grounding` と、既存の時代考証3スキルを比較し、このリポジトリからの参照と保守範囲を整理する。リポジトリの移設や、全分野向けの共通基盤の新設は行わない。

## どこを正本にするか

| 作業 | 層 | 今回参照する正本 | このリポジトリでの扱い |
|---|---|---|---|
| 資料を探す・取得する・保存する・索引を作る | 共通基礎として再利用できる手順 | `video-production-skills` の `period-source-ingestion` | 歴史調査で必要な時に本文を読む。手順を再定義しない |
| 資料の信頼性と対象への適合を分けて判定する | 共通基礎として再利用できる手順 | 同 `period-source-criticism-gate` | Tier表を複製しない。根拠としての採用と、主張の確定を分ける |
| 記録・注・評・物語の読み分け、規範の対立、時代をまたぐ一般化の限界 | 歴史という分野の方法 | [historical-context-grounding](../skills/historical-context-grounding/SKILL.md) | 歴史の判断に固有の指針を担当。Jevや映像に依存させない |
| 画面・所作・道具・空間と、素材の版ごとの整合 | 映像への接続 | `video-production-skills` の `period-accuracy-review` | 映像・脚本・絵コンテを扱う時だけ参照 |
| 人物に何を知らせるか、選択肢、定性的な人物表現、モデル実測と評価 | Jevへの接続 | [historical-judgment-evaluation.md](../skills/jev-shared/references/historical-judgment-evaluation.md) | 歴史の解釈を複製せず、人物視点と実験へ反映する |
| 個別案件の資料・考証判断・実送信・生応答・評価 | 案件成果物 | 利用者が指定した案件・実験の保存先 | スキル集に個別結果を入れない |

「共通基礎」はどの分野にもそのまま適用できるという意味ではない。今回は時代考証の既存手順を再利用する。モデル仕様、医療、法律などへ、歴史資料向けのTierや映像固有の出力を一律に広げない。分野をまたいで安定して共有できる契約が分かってから、共通リポジトリ等への切り出しを検討する。

## 比較から分かった重複と違い

- 新スキルにあった探索・本文確認・出典記録は、既存の取得手順と重なっていた。その詳細を削り、版と利用条件を示した参照へ置き換えた。
- 既存の資料判定は発行主体と対象への適合を別に扱い、採用可否と歴史的判断の確定を区別する。この基準を新スキルへコピーすると更新時に食い違うため、既存側を参照する。
- 既存レビューは人物の社会関係も対象にするが、最終成果物は場面・素材・HIST項目の整合。人物の認識を制約して行動を問う実験とは出力が異なるので、レビュー全体をゲームへ流用しない。
- 新スキルにあった「Scoreを使うか」「人物に渡す情報」「期待する確率に寄せない比較」は用途側へ集約する。歴史だけを調べる作業に、Jevの用語や工程を要求しない。

## 呼び出し方

Jevの設計・評価 → Jev用の接続資料 → 歴史的な読み分け → 必要な資料取得・判定手順、という順に必要な部分だけ読む。映像レビューは既存の映像側の入口を維持する。他リポジトリのスキルの挙動は今回変更していない。

これは同じエージェントが必要な指示を読み込む接続であり、別エージェントへの委任・メッセージ送信・インストールを意味しない。既存の利用権限と作業範囲は変わらない。

参照先が手元にあるか、利用者に読めるかを確認する。版、出力先の対応、読めない場合の代替実施は[参照する資料手順と利用条件](../skills/historical-context-grounding/references/source-workflows.md)にまとめる。そこをこの参照関係の版管理の正本とし、同じハッシュ一覧を複数箇所へ転載しない。

## 更新と保守

- 取得・索引の変更は取得スキル、資料の採用基準は判定スキル、映像の観察項目は映像レビュー、史料の読み分けは歴史スキル、入力と実験はJev用の接続資料で直す。
- 他リポジトリの変更が必要になった場合は、現在の呼出側の追記だけで新しい基準に変更したことにしない。提供側の規約と影響する利用先を確認して対応する。
- 参照版を更新する時は差分と下流の出力契約を確認する。既存案件の実行記録は書き換えず、新しい実施から使った版を記録する。
- 共通化の候補が増えたら、この表に用途と違いを追記する。別リポジトリへの移設、公開範囲、依存の配布方式は、その時に具体的な移行案として判断する。

## 今回の整理の限界

取得と資料判定の保守元は引き続き非公開の `video-production-skills`。公開の `llm-skills` だけを持つ利用者には、その手順が常に利用可能とは限らない。このため現在は必須の外部依存にせず、読めた手順と代替実施を区別する。共有手順を誰でも取得できる配布形態にするかは未決定。

この整理は責務と参照の第一段階であり、複数ホストでの実運用や、分野横断の考証品質を実証したものではない。最初の利用時に、参照可否、出力先、版の記録が実際に守れるかを確認して改善する。
