# 時代考証スキルの責務

2026-11-02作成、2026-11-03改訂。`historical-context-grounding`と、関連する手順の責務と保守範囲を整理する。

## どこを正本にするか

| 作業 | 層 | 正本 | このリポジトリでの扱い |
|---|---|---|---|
| 資料を探す・取得する・保存する・索引を作る | 共通基礎 | 利用者や案件が指定する手順。指定がなければ[基本手順](../skills/historical-context-grounding/references/source-workflows.md) | 指定の手順を再定義しない |
| 資料の信頼性と対象への適合を分けて判定する | 共通基礎 | 同上 | 指定の採用基準を複製しない。根拠としての採用と、主張の確定を分ける |
| 記録・注・評・物語の読み分け、規範の対立、時代をまたぐ一般化の限界 | 歴史という分野の方法 | [historical-context-grounding](../skills/historical-context-grounding/SKILL.md) | 歴史の判断に固有の指針を担当。Jevや映像に依存させない |
| 映像・脚本などの場面の整合 | 用途への接続 | 用途側の手順 | このリポジトリでは扱わない |
| 入力点検、反復・条件比較、分布の解釈、実験の記録と限界 | Jev共通手順 | [judgment-input-and-sensitivity.md](../skills/jev-shared/references/judgment-input-and-sensitivity.md) | 横断的な実験手順の正本。較正の合否や観測契約は各担当に残す |
| 歴史的な人物に何を知らせるか、選択肢、定性的な人物表現、人による評価 | Jevへの接続 | [historical-judgment-evaluation.md](../skills/jev-shared/references/historical-judgment-evaluation.md) | 歴史の解釈を複製せず、人物視点と実験へ反映する |
| 個別案件の資料・考証判断・実送信・生応答・評価 | 案件成果物 | 利用者が指定した案件・実験の保存先 | スキル集に個別結果を入れない |

「共通基礎」は、どの分野にもそのまま適用できるという意味ではない。モデル仕様、医療、法律などへ、歴史資料向けの基準を一律に広げない。

## 呼び出し方

Jevの設計・評価 → Jev用の接続資料 → 歴史的な読み分け → 必要に応じて資料の取得・判定の手順、の順に必要な部分だけ読む。これは同じエージェントが必要な指示を読み込む接続であり、別エージェントへの委任・インストールを意味しない。

## 更新と保守

- 史料の読み分けは歴史スキル、横断的な入力点検と実験手順はJev共通参照、歴史固有の人物視点と評価はJev用の接続資料で直す。資料の取得・判定の手順を指定の手順側で変えた場合、こちらの呼出側の追記だけで新しい基準に変えたことにしない。
- 既存案件の実行記録は書き換えず、新しい実施から使った版を記録する。

## 限界

この整理は責務と参照の第一段階であり、複数ホストでの実運用や、分野横断の考証品質を実証したものではない。
