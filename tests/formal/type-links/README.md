# 型の結びつきのモデル

[型の一覧](../../../skills/dev-shared/references/artifact-types.md)の「識別子と結びつき」の決まりのうち、通常の道の抜け漏れの検査 1〜8、16〜22 と、それが支える結びつきを Alloy で表し、決まりそのものの矛盾と穴を探す。案件の成果物は検査しない。正本は型の一覧で、このモデルは写し。

2段で進めた（2026-11-17 の利用者の承認）。1段目は検査 1〜8 を写した試行のモデルで、穴の候補を見つけた（下の「1段目で見つかったこと」）。2段目（2026-11-19）は、持ち主の決定に沿って型の一覧の検査を直し、このモデルで反例が消えることを確かめた。

仕様化の中核（要件、受入条件、テストケース、作業、業務規則、設計の判断）だけを表した。画面と文面（検査 11〜15）、ドメインモデル（9、10）、軽い道は表していない。

## 仮定と範囲

- 「今回の範囲」は、モデルの中のものすべてとする。
- 検査は文のとおりに写す。結びつきの表の多さは事実にせず、述語にして、検査を通れば成り立つかを主張（H9、H12）で見る。
- 文の読みを選んだ所:
  - 検査 7 の「テストで確かめない規則には、手段と理由がある」は、第1文と同じく有効な規則に限ると読んだ。
  - 規則の「満たすケース」は、規則を指すテストケースのうち「破るケース」の印の無いものとした。印はケースごとで、規則ごとではない。
  - 検査 20 の「作業をすべて終えたとするとき」は、作業が1つ以上あり、どれも終わったとき、とした（作業が無いときには求めない）。
  - 検査 16 の第2文は、廃止していない要件に1つ以上属せばよいと読んだ（廃止した要件にも属する形は、検査 16 では拾わず、完了前の監査の識別子の突き合わせが指摘にする。検査 4・17 の、廃止した受入条件にも結ばれた作業とテストケースも同じ）。第1文は、廃止した受入条件にも要件を求める（属する先を失わせないため。持ち主の決定の「廃止したものを含めない」の例外）。
  - 検査 19 の「結んだ作業がすべて終わったとき」は、結んだ作業が1つ以上あるとき、とした（無ければ検査 3 が指摘する）。
- 検査 8、18 の「存在し」は表せない（指す先は必ずモデルの中の規則なので、指す先の無い参照を作れない）。確かめていない。
- 出どころは種類を区別しない（問題台帳の問題、回帰の基準の検証点などを1つの集合にまとめた）。
- 廃止したテストケースと作業は表していない。検査は廃止していないものだけを見る（型の一覧の節の頭）ので、モデルのケースと作業はどれも廃止していないものとする。「決定待ち」の作業も表していない。
- 範囲は、どのコマンドも各集合を最大5個まで。反例が無いと言えるのは、この範囲の中だけ。範囲を変えて流すときは、写しを作って ` for 5` を ` for 3` などに置き換える。
- 結びつきの形だけを見る。受入条件の文が判定できる形か、のような中身は見ない。

## 1段目で見つかったこと（2026-11-17）

どれも、モデルの反例と、決まりの文との対応を読んで確かめたところまで。案件の成果物で再現したものではない。

1. 作業が終わっても、受入条件のテストが一度も通っていないことがある（H1、H2）。受入条件のテストケースが既にあるもので、どの作業にも結ばれていない経路と、受入条件に結んだ作業とそのケースを結んだ作業が別である経路の2つ（H3）。
2. 否定のケースと、業務規則の満たすケース・破るケースも、同じ理由で通らないまま終われる（H4、H5）。
3. 廃止の扱いが、両方向にずれていた。弱い向き（H6、H7）と、廃止したものにも求める強い向き（S1〜S4）。
4. テストケースが、廃止した規則や仮説の規則を確かめていても通る（H8）。
5. 受入条件も出どころも無いテストケースと、どの要件にも属さない受入条件が通る（H9、H12）。
6. 終わった作業の、先に終わっている必要がある作業が終わっていなくても通る（H10）。依存の輪も通る（H11）。

## 2段目の決定（2026-11-19、利用者）

- 作業に結ばれていない、前からあるテストケースも、完了の前に通った記録を要る（回帰として別に流してよい）。→ 検査 19。
- 否定を含む受入条件に否定のケースを求めるのは、テストで確かめない理由が無いものだけ。→ 検査 2 の直し。
- 検査の「すべての」「指す」に、廃止したものを含めない。→ 検査 1〜3、8 の直し。廃止していない要件と受入条件の結びつきは、検査 1 と 16 で見る。検査 16 の第1文だけは、廃止した受入条件にも要件を求める（属する先を失わせないため）。
- 残りの穴も塞ぐ。→ 検査 16（H7、H12）、17（H9）、18（H8）、20（H5）、21（H10）、22（H11）。
- H3 は、塞ぐ候補として示さなかった（担当の判断）。作業が、ほかの受入条件のケースを結んで通してもよい。H3 が支えていた H1・H2 は、検査 19 で成り立つ。

レビュー（Fable P-458、Sol P-459）の後の決定（同日、利用者）:

- 検査 19 は、受入条件に結んだ作業がすべて終わったときに求める（共通の土台の作業を先に終えられる。S6）。
- 検査 19 は、受入条件に結ばれたテストケースのどれもが通った記録を持つことを求める（1件通ればよい、ではない。H13）。
- 検査の「テストケース」「作業」は、廃止していないものを指す（節の頭に書いた）。
- 検査 4 と 17 は、廃止していない受入条件か出どころを求める（S7、S8）。
