# 今の状態の安全の点検のプロファイルのモデル

`skills/dev-profile-exposure-sweep` の工程の順序、条件、戻る流れ、人の決定を TLA+ で表し、TLC で検査する。共通の注意は [../README.md](../README.md)。

## 確かめる性質

| 性質 | プロファイルの決まり |
|---|---|
| `SendOnlyWithPermission` | 要求を送るのは、受付か点検し直しで人が許可を記録したときだけ（無ければ要求を作るところまで） |
| `CheckBeforeDecide` | 人が決めるのは、点検を終えた後 |
| `DecisionBeforeFinal` | 問題がある行か人の判断が要る行があれば、人が決めてから最終確認へ |
| `CheckBeforeFinal` | 最終確認は、点検を終えた後 |
| `Terminates` | どの依頼でも、いつか終わる（公平性の下で） |

## 仮定と範囲

- 許可の有無、問題の有無、点検し直し、許可を足すかは、初期状態で非決定に選ぶ。
- `triage-ask` からの点検し直しは1回まで起きうるとする。
- 表していないもの: 単位の中身（送る要求の種類と数、応答とコードの区分）、許可の期限切れ、中断と再開、直す作業（この組み合わせの外）。
